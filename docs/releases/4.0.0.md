Pierwsze stabilne wydanie ReactKL. Zawiera zmiany z gałęzi ReactKL od wydania `v0.1.0-alpha.1`.

## Najważniejsze zmiany

- Kreator karty leczenia z czterema etapami, podsumowaniem, podglądem i skrótami klawiszowymi. Zapamiętany wariant leku można ponownie użyć zgodnie z wybranym gatunkiem.
- Katalog i podgląd ChPL w aplikacji, dodatkowy widok tabel AG Grid, ustawienia skórek, motywu i skalowania.
- Wspólne archiwum SQL, karty z sekcją III, eksport PDF, edycja zapisanych kart, kosz oraz kopie zapasowe.
- React 19.3.1, Ant Design 6.7.1, TypeScript 7.0.2, Vite 8.3.8 i .NET 11. Aktualizator rozpoznaje również numery RC.

## Instalacja i dane

Pobierz instalator Windows x64 i plik z sumą SHA-256 z załączników wydania. Na nowym serwerze instalator dostarcza aktualny pakiet startowy katalogu z bazy SQLite, dokumenty ChPL i dodatki katalogowe z repozytorium. Istniejącą konfigurację SQL i katalog aktualizuj zgodnie z instrukcją w [README](https://github.com/VViktorr/Karty-leczenia-zwierzat/blob/v4.0.0/README.md). Dane produkcyjne nie są częścią wydania GitHub.
